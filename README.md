# Student Result Management System

A modular Python application for managing students and their academic
results.

## Features

### Student Management

- Add students
- View students
- Search students
- Delete students

### Result Management

- Enter marks
- Calculate total marks
- Calculate percentage
- Calculate grade
- Determine pass/fail status
- Update marks
- Delete results
- View student result

### Reports

- Class statistics
- Average subject marks
- Top 5 students
- Highest percentage
- Lowest percentage
- Pass/fail count

## Technologies

- Python
- JSON
- File Handling
- Functions
- Modules
- Lists and Dictionaries
